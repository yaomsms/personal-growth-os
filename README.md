# 🌱 成长OS - 个人成长操作系统

一个功能完整的个人成长管理PWA应用，支持手机/平板/电脑全平台使用，可添加到主屏幕像App一样全屏运行。

## 🚀 部署方式

### 方式一：静态托管（推荐）

将整个 `personal-growth-os` 文件夹上传到任意静态托管服务：

**Vercel（推荐，免费）：**
```bash
# 1. 安装 Vercel CLI
npm i -g vercel

# 2. 进入目录并部署
cd personal-growth-os
vercel
```

**Netlify（免费）：**
- 直接拖拽文件夹到 https://app.netlify.com/drop
- 或连接GitHub仓库自动部署

**GitHub Pages：**
```bash
# 将代码推送到GitHub仓库
# 在仓库 Settings → Pages 中选择 main 分支
```

**Cloudflare Pages：**
- 连接GitHub仓库，构建命令留空，输出目录填 `/`

### 方式二：自有服务器

将文件夹上传到服务器，用Nginx/Apache提供静态文件服务：

```nginx
server {
    listen 80;
    server_name your-domain.com;
    root /path/to/personal-growth-os;
    index index.html;
    
    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

### 方式三：本地运行

```bash
# Python
cd personal-growth-os
python3 -m http.server 8080

# Node.js
npx serve .

# 然后访问 http://localhost:8080
```

## 📱 添加到主屏幕（PWA）

### iOS (Safari)
1. 用Safari打开网站
2. 点击底部分享按钮（方框带向上箭头）
3. 向下滑动，选择「添加到主屏幕」
4. 点击「添加」

### Android (Chrome)
1. 用Chrome打开网站
2. 点击右上角菜单（三个点）
3. 选择「安装应用」或「添加到主屏幕」
4. 点击「安装」

添加后就可以像普通App一样全屏使用了！

## 💾 数据存储

- 所有数据保存在浏览器本地（localStorage）
- 数据不会上传到任何服务器
- 支持数据导出为JSON文件备份
- 支持从JSON文件导入恢复数据
- 清除浏览器数据会丢失所有记录，请定期备份
